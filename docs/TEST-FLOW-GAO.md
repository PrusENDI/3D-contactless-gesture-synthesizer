## 17. GAO 触发打通 —— 根因是缺 `<Expressions>`（2026-10-30）

### 17.1 根因

生成的 `RTL_GAO/ao_0/gw_ao_expression.v` 里：

| 版本 | 内容 | 后果 |
| --- | --- | --- |
| 修复前 | 16 条全是 `1`（常量真） | 触发条件恒真 → 武装后第一个采样就"命中"，缓冲区里永远是空闲快照 |
| **修复后** | `CORE0_DF_AO_EXPRESSION_0  match[0]` | 引用了 MatchUnit 0 → 真正按 `wt_apply_valid_q == 1` 触发 |

修复方式：在 `<AoCore>` 内补上

```xml
<Expressions type="Static">
    <Expression>M0</Expression>
</Expressions>
```

（`M0` 选中 MatchUnit 0；GUI 生成的 `.gao` 里也有这一段，我们之前漏了。）

### 17.2 抓到的完整 APPLY 时间线（位流 `8C8BB3EF…998E`）

```
t=  508 us  uart data 0x62->0x33, valid 0->1        (WT_VERSION 写命令的最后一个字节)
t=  509 us  valid 1->0
t=  511 us  cmd_valid 0->1, cmd_address 0x74->0x78  (APPLY 命令)
t=  512 us  cmd_valid 1->0, cmd_ready 1->0, wt_apply_valid_q 0->1   ← P1 打拍投放
t=  513 us  wt_apply_valid_q 1->0, state 0->1, wt_apply_busy 0->1
t= 1538 us  state 1->2, crc_final_captured 0->0xEDDC (CRC 扫描结束，1026 拍 ≈ 12.8 µs)
t= 1539 us  cmd_ready 0->1, state 2->0, wt_apply_done 1, wt_apply_ok 1,
            wt_apply_busy 1->0, wt_active_version 0->1              ← R12 结果握手
t= 1540 us  wt_apply_done 1->0, rsp_valid 0->1
t= 1541 us  rsp_valid 1->0
```

**这是本项目第一份独立仪器的板上证据**，逐条对应：

| 结论 | 波形证据 |
| --- | --- |
| P1 打拍生效 | `cmd_valid` 在 511，`wt_apply_valid_q` 在 **512**（晚一拍），目标寄存器此时已是新值 |
| CRC 扫描周期数正确 | 513 → 1538 = **1025 拍**（1024 个样本 + 1 拍流水） |
| CRC 结果正确 | `crc_final_captured = 0xEDDC` = 主机 CRC |
| R12 结果握手 | `wt_apply_done`/`wt_apply_ok` 与 `active_version 0→1` **同拍**，`rsp_valid` 紧随其后 |
| 应答来自本次事务 | 应答在 done 之后一拍发出，不再是上一条的粘滞值 |
