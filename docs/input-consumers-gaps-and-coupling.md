## 9. 音高映射按设计文档重做（2026-10-31）

### 9.1 为什么"音高变了但声音没变"

`v2_note_increment_rom` 只有 **57/60/62/64/67/69/72** 七个音（A 小调五声），
**default = 0**。而旧 `map_note` 把 y 线性映射到 **24..96**，绝大多数音符落在
ROM 之外 → `increment = 0` → 振荡器不跑，声音自然不跟着变。

### 9.2 按 `docs/lead-mapping-report-2026-10-22.md` 重写

```
y ∈ [11534, 54001]  →  G3(55) .. C5(72)，每半音 2498 counts
量化到 A 小调五声 {55,57,60,62,64,67,69,72}
```

- `map_note` 改为 8 段比较（无除法）；
- `note_boundary` 改为五声边界（55/57/60/62/64/67/69/72）；
- `v2_note_increment_rom` 补上 **55 = 17537476**（G3），使五声音阶完整。

### 9.3 板上结果（位流 `74070D0C…6D2F`）

```
MODE=1  note=64  active=1  gate=1
```

音符已落在 ROM 集合内（64 = E4），不再是 24/95 这种无 increment 的音。

### 9.4 说明：这不是"触摸"输入

设计输入是**空中手位**（近场电场），`y` 是手的高度、`z` 是距离。
光标滤波器的 engage 条件用 `in_z < Z_ENGAGE`（接近阈值），本就是"手进入感应区"，
不是触摸判定；`cursor_engaged` 作为 gate 的语义与此一致。

### 9.5 待实测

手在感应区上下移动时，`note` 应在 55/57/60/62/64/67/69/72 之间跳变，声音随之变调。
