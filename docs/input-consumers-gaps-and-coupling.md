## 8. LIVE 跟随 Y 轴生效（2026-10-31，触摸实测）

### 8.1 根因（两个）

1. `cursor_point_valid` 是**一拍脉冲**，却被当成"每帧有效 + 门控" → 除首次 engage 外
   每帧 `bad_frame=1`，规则不执行；
2. 门控同样只在一拍为 1 → 永远不发 note-off。

### 8.2 修复

```verilog
wire cursor_engaged = (cursor_state == ENGAGED) || (cursor_state == REBASED);
.frame_valid(cursor_frame_done && cursor_engaged)
.touch(cursor_engaged), .bow(cursor_engaged)
```
