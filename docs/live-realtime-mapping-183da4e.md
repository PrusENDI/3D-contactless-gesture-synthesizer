## 10. 门控的作用与电平穿越的区间设计

### 10.1 门控（gate）到底起什么作用

门控与音高是**两条独立的轴**：

| 作用 | 说明 |
| --- | --- |
| **1. 何时出声（onset）** | `touch`：手接触/进入接触判定时；`bow`：左右往返的每一次折返 |
| **2. 音有多长（duration）** | `touch`：接触时长；`bow`：半程时长（往返一次=两个音） |
| **3. 同音重复** | 同一个音级连续被门控切分成多个音；没有门控就只是一个长音 |
| **4. 段间静音** | 门控关闭即停音（spec §4「时值=接触时长」） |

没有门控，就只有"音高变化时才换音、否则一直响"——这正是我们现在听到的持续音。
参考实现里 `articulation = legato if duration >= 8 else pluck`，说明**时值本身就是音乐参数**。

### 10.2 电平穿越的区间设计

1. **连续音高**：`pitch = 55 + 17·(y - 11534)/42467`，即 **1 半音 = 2498 counts**。
2. **量化**：只落在 A 小调五声 `{55,57,60,62,64,67,69,72}`。
3. **穿越判决（滞回）**：参考实现

```python
def _quantize_hysteresis(raw, pitches, previous, hysteresis):
    return previous if previous in pitches and abs(raw - previous) <= hysteresis else target
```

`hysteresis = 0.10`（**半音**），即：raw 与当前音相差 ≤0.1 半音就保持，否则取最近音。

4. **换算成 counts**：`0.10 半音 × 2498 ≈ 250 counts`。

**当前 RTL 的问题**：用的是"边界 ± `HYSTERESIS=1024`"，即 **0.41 半音**，是参考值的 **4 倍**。
后果：音高要移动近半个半音才换音，听起来"黏住不动"——与实测"音高很少变化"一致。

**建议**：`HYSTERESIS` 1024 → **250**，并把边界表固定为五声（已做）。

| 音 | 起始 y（含） | 结束 y（不含） |
| --- | --- | --- |
| 55 (G3) | 11534 | 16530 |

滞回带：每条边界两侧各 ±250 counts（切换需要越过边界 250，回退也要 250）。

### 10.4 门控与穿越的组合规则（实时）

```text
每帧：
  note_now = quantise_hysteresis(y)          // 滞回穿越
  if gate_open && note_now != note_playing:  // 穿越
       end previous note, start note_now     // 由门控决定时值
  if gate 关闭:
       end note (若在响)
```

大跳抑制：若从 note_playing 到 note_now 跨 ≥3 个音级且用时 < 若干 tick，
则**不产生经过音**，直接切到目标音（spec §4）。
