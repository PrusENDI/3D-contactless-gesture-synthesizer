寄存器：`WT_SELECT(0x60) = {step[22:0], morph_en, 6'b0, table[1:0]}`，写掩码 `0xFFFFFF07`。
`step = round(2^25/(周期秒×48000))`，20 s → 35。

### 证据

- L1 `gate.py --compile` 0/0；L2 `sim.py` PASS（RAM=0/1 一致，4 个失败属基线）；
- L3 生产位流 `d5176b93…`（CLS 10410/11520，register 8655），复制在 `impl/v2_board_top_morph1_prod/`；
- 板上：三帧上传 CRC/APPLY 全 0；`0xE8` position 斜率 6547 units/s → 单程 20.02 s；
- GAO（80 MHz，25.6 µs）：`frac=0x27`、a=0xE6C3、b=0xA8F3 → `0xDD58`，与公式逐位一致；
- GAO（48 kHz，42.7 ms）三帧频谱：A 纯正弦（h2..h16 ≤ −83 dB）、B 锯齿（1/k）、C 方波（偶次 ≤ −82 dB）；
- LIVE 实测：arp 模式（`THRESHOLDS[23]=1`）下 `active=1/gate=1`，note 随 Y 变，`0xD4` 事件计数增长，position 同时在扫。

### 本轮打掉的坑

1. `frac` 未与寄存后的表样本对齐 → 每个帧对切换点有一声咔嗒；`tb_wt_morph` 先红后绿。
2. 回退只检查帧 B → 改为 A/B 任一有效才用。
3. host CRC 字节序（小端 vs 器件 MSB-first）。
4. 音频 GAO 触发用 1 拍脉冲 → 改 `mode_wt_play` 电平。
5. 序列号重复（`err=5`）、`WT_SELECT` 写会清 morph（上传脚本必须 `-PostSelect`）。

### 已知遗留

- 构建仍有 25 条负 setup slack（worst −1.690 ns，声部事件/音符 ROM 锥），属既有问题（`gao_tick` 更差）；
  按 skill 口径，功能结论仍属“暂定”，但本功能路径不在最差路径上。
- `frames.json` 的 `path` 是绝对路径；docstring 写 N 帧但 CLI 收 3 个。
- LIVE 逐帧追踪模式（`THRESHOLDS[23]=0`）需要从左边缘起弓才会出第一个音；arp 模式不需要。
- 隔夜掉电位流会丢，测试前先读 `0xB0`。
