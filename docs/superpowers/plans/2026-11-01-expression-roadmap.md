## 1. 为什么做这两件

赛题原文（用户提供）：

| # | 要求 | 本轮覆盖情况 |
| --- | --- | --- |
| R1 | 复音 ≥32 / 加法 ≥32 路 | 已有 32 声部；按评分口径（独立相位累加器 + 频率调控 + 包络控制）如实按 **32 路**申报，不追 64 |
| R2 | ≥3 维表情 + ≥2 音色切换 + 混响/延迟/合唱 | 本轮补**力度**这一维 + 滤波器改善音色；音色切换已有（3 帧 morph + `WT_SELECT`）；**效果器只有现存的 delay+comb，不做混响/合唱** |
| R3 | 延迟 ≤5 ms、可视化 | 延迟按"事件→DAC"口径（不含 MGC3130），现路径远小于 5 ms；**可视化不做** |
| R4 | 脱机 LED 指引 / 蓝牙 App | 不做 |
| S1 | 一路 = 相位累加器 + 频率调控 + 包络控制 | 32 声部已满足；本轮让"包络控制"第一次真的作用于幅度 |
| S2 | 吞吐量 = 活跃振荡器 × 采样率 | 32 × 48 kHz = 1.54 M（如实申报） |
| S3 | 测试模式多路不同频率 + 频谱 N 峰 | 独立测试位流（阶段 P3） |

**两个直接动因**（有代码证据，见 §2）：包络从来没有乘到音频上（音是恒幅开关，所以单薄）；
没有滤波器（频谱永远是波表原样）。

## 3. 要做的三件事

### P1 力度 + VCA（1 轮）——**已完成（2026-11-01 晚）**

> 落地记录：`5337ac0`（VCA + 力度）、`97da308`（失谐）、`0218fa6`（激活改走邮箱，修时序）。
> 任务级计划与偏差在 `2026-11-01-vca-and-detune.md`，资源/时序对比在 `docs/progress-2026-11-01.md`。
> 与下文原始设计的两处差别：力度不是"包络峰值 `velocity×257`"而是 `env×velocity>>8`（省一个乘法器，
> 峰值仍由力度决定）；失谐按力度的两位分四档，落在激活字里（`step_b = base - (base >> (11 - gain[7:6]))`）。

**做什么**

- `v2_voice_engine_banked`：把 `calc_envelope` 乘进振荡器输出（每声部一个 16 bit 包络，扫描管线
  一拍一个声部，所以**一个乘法器**时分复用即可）；
- 力度不再是"再压几档"，而是**包络的峰值**：`env_peak = velocity × 257`（0..65535），
  于是"手越近越响"变成真正的起音幅度差；
- 保留现有四段常数（ATTACK 4096、DECAY 256、SUSTAIN 49152、RELEASE 1024）——本轮不做 ADSR 可调。

**验收**

- 新 tb `tb_voice_vca`：常量样本 + 阶梯力度 → 断言输出峰值 = `sample × velocity` 的期望阶梯；
  断言释放是 48 个采样（≈1 ms）的斜坡而不是瞬间归零；
- 板上：GAO 抓 `i2s_sample` 断言音头/音尾是斜坡；手靠近/远离能听出强弱。

### P2 全局滤波器 + LFO（2 轮）

**做什么**

- 二阶低通（TDF-II 或状态变量，12 dB/oct），截止 20 Hz…18 kHz，Q 0.5…8；
- **位置：最终 I2S mux 之前**，LIVE / WT_PLAY / PLAY 三条出口都过它；
- LFO：三角波（比正弦省面积），0.05…20 Hz，深度 0…1，**加性**叠到截止控制字上；
- 旁路位（默认旁路，避免一上电就变色）。

**控制面**

- 新增两个 RW CSR，占用契约里**从未实现**的 `0x40/0x44`（原 `DIAG_AUDIO` / `DIAG_ROUTER`，
  仓库与脚本里没有任何使用者）：
  - `0x40 FILTER`：`[15:0]` 截止、`[23:16]` 共振 Q、`[24]` 旁路；
  - `0x44 LFO`：`[15:0]` 速率、`[23:16]` 深度、`[24]` 使能；
- 契约包同步改成 RW 并写掩码；`docs/host-tools-and-gui-controls.md` 的寄存器表更新。

**验收**

- tb `tb_filter`：白噪声/冲激输入，测 −3 dB 点与控制字的对应关系（至少 3 个频点）、Q 对峰的影响；
- tb `tb_lfo`：LFO 周期与控制字对应、深度为 0 时截止不变；
- 板上：GAO 抓 `i2s_sample`，固定音高下看频谱重心随 LFO 周期移动；旁路开/关对比。

### P3 独立测试位流（1 轮，可与 P2 并行）

**做什么**

- `USE_TEST_MODE=1` 的独立构建（生产位流保持 0），把测试模式升级成 **N 路不同频率**
  （N = 1/8/32），用于赛题现场验证 "多路音频 → 频谱 N 个独立谱峰"；
- 记录测试位流自己的 `bitstream_sha256`，与生产位流分开记。

**验收**

- 板上烧测试位流，GAO/频谱仪数出对应数量的独立谱峰；`0xA0` 读回不再是 0。
