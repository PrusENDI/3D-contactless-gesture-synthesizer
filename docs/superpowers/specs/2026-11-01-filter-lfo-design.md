# 整机低通滤波器 + LFO 扫截止：设计（2026-11-01，评审后修订 r2）

> 目标版本：`mgc3130_clean` HEAD 之后（P1 已完成）。本文件是 P2 的设计，批准后才写任务级计划。
> **r2 修订原因**：独立评审指出 r1 的共振阈值算法错了（用连续时间模型、忽略了反馈的一拍延迟），
> 我独立复核后确认。§5.2/§5.3/§6 因此重写，控制面与 LFO 不变。逐条答复见 §10。

## 1. 意图与为什么

现在的音色薄，根因不是振荡器不够，而是**没有任何频谱塑形**：32 个声部把满幅波表直接送进 I2S，
高次谐波全在，听感"亮而空"。标准合成器的听感一半来自滤波器——尤其是**带共振的低通**与
**缓慢扫动的截止频率**（LFO → cutoff）。赛题的"表情"项也希望整机有可听、可演示的连续变化。

所以 P2 只做两件事：一个**整机共用的 4 极点低通**（24 dB/oct，带共振），一个**三角 LFO**
把截止频率在对数域上缓慢扫动。上电默认**旁路**，行为与今天完全一致；主机显式打开后才改变音色，
因此既往验收过的电平/频谱证据不会失效。

## 2. 目标

1. 三条音频出口（`PLAY` 的 32 声部、`LIVE` 单声部、`WT_PLAY` 台架）都经过同一个滤波器；
2. 截止频率、共振、LFO 速率/深度可经 CSR 控制，且**可读回**；
3. 旁路时**比特级透明**（输出直通，滤波器照常运行，只是不选它）；
4. 任何 (截止 × 共振 × LFO) 组合都不发散，输出恒在 int16 内；
5. 面积 ≤ 450 LUT、≤ 6 DSP、1 BSRAM（预算：CLS 剩 1010、DSP 剩 20、BSRAM 剩 19）。

## 3. 非目标 / 反目标

- 不做滤波包络（ADSR→截止）、不做键盘跟踪、不做高通/带通/陷波；
- 不做每声部独立滤波（整机一个，用户已定）；
- 不做 LFO 波形选择（只有三角）、不做 BPM 同步；
- **不做自激**（理由见 §5.2，一行常数即可改成允许）；
- 不重做效果器（`v2_fx_lite` 保持原样）；
- **反目标**：为了让规格好看而把"截止 18 kHz"当成 −3 dB 点——两者差一个常数，§5.4 写清楚。

## 4. 约束（来自现有代码，不是猜的）

| 约束 | 值 | 出处 |
| --- | --- | --- |
| 采样率 / 时钟 | 48 kHz / 80 MHz → **每个采样 1667 个时钟** | `i2s_pcm5102a_tx` `CLK_HZ(80e6) SAMPLE_HZ(48e3)` |
| 插入点 | `i2s_sample` 的 4 路 mux 之后（三条出口都经过） | `mgc3130_v2_top.sv:658` |
| **滤波器的时基** | **`sample_ce`**（连续 48 kHz 节拍），**不是** mux 后的 `i2s_sample_valid` | 见 §5.6 与 §10 Q2 |
| 延迟 | 1 个采样（20.8 µs），不延迟 I2S 的 valid | 同上 |
| 面积余量 | CLS 10510/11520、DSP 8/28、BSRAM 37/56 | `impl/v2_board_top_vca_detune_mbox` |
| 时序余量 | worst −3.214 ns（在 UART，不在音频路径） | 同上 `.tr` |

**关键推论**：1667 个时钟/采样意味着滤波器可以多周期流水；**DSP 富余、LUT 紧张**，所以用
并行乘法器（每级一个）而不是时分复用，用 1 块 BSRAM 存系数表。

## 5. 方案

### 5.1 三个候选与取舍（用户选了 B）

| | 结构 | 音色 | 代价 |
| --- | --- | --- | --- |
| A | 状态变量 12 dB/oct | 干净、Q 可到 8 | tan 查表；−3 dB 上限更高 |
| **B ✅** | **梯形 4 极点 24 dB/oct，ZDF 解反馈** | **像合成器：厚、共振峰均匀、可自激** | 1 BSRAM（G 表 + 倒数表）+ 4~6 DSP；8 个状态 |
| C | 两级一极点级联 12 dB/oct，无共振 | 只压高频 | 最便宜，放弃共振 |

选 B 的理由：用户诉求是"音色单薄"，24 dB + 共振最能改观；系数在对数域（1/48 八度一档），
LFO 直接加在对数域上就是音乐化扫频。代价是 r1 低估的那一点（1 块 BSRAM + 倒数表），
在 19 块空闲 BSRAM 里可以接受。

### 5.2 结构（r2 重写）

每级用**双线性（TPT）一极点**，全环做**零延迟反馈（ZDF）**解算：

```
            ┌──────────────────────────────────────────┐
x ──►(+)──► u ──► [P1] ──► [P2] ──► [P3] ──► [P4] ──► y4 ──► 饱和 ──► out
      ▲-                                                    │
      └──── K·S ◄──── ZDF 解 ───────────────────────────────┘

每级： v_i = G·(u_i − s_i)， y_i = v_i + s_i， s_i ← y_i + v_i
四极点： y4 = G⁴·u + S，  S = (1−G)·(G³s₁ + G²s₂ + G·s₃ + s₄)
反馈解： u = (x − K·S) / (1 + K·G⁴)
```

**为什么必须 ZDF（这是 r1 的错误）**：若像 r1 那样把反馈取上一拍的 `y4`（一拍延迟），
振荡阈值 `Kcrit` 与截止频率强相关且**非单调**（实测：ci=0 时 1.00、ci=8 时 3.61、
ci=16 时 11.18、ci=32 时 9.00、ci=96 时 4.6）。后果是：ci ≤ 8（"全开"那一端）K=3.9
已经超过阈值 → 变成 24 kHz 满幅方波；而 ci=32 附近 K ≤ 3.9 又完全激不起共振。

ZDF 解算后（实测，见 §5.3 表）：**|P| = 0.2500、∠P = ±180° 恰好落在设计 fc 上，与截止无关**，
于是 **Kcrit = 4.000 对所有截止成立**，K=3.75 的峰值 **+14.0…+15.2 dB**（从 40 Hz 到 18 kHz
只差 1.2 dB）。这就是要的"旋钮含义一致"。

- `K = res·3.75/256`（res 0..255），**上限 3.75 < 4**：不做自激。想允许自激只需把上限改成 4.02，
  但那时输出幅度由饱和器决定、会盖掉别的声部，本轮不做；
- 输出整型饱和（共振峰值 +15 dB 会削顶，这是刻意的、可听的控制）；
- 反馈项 `K·S` 用宽位宽算，不先饱和（先饱和会改变谐振频率）。

### 5.3 系数与截止映射（r2 重写，全部实测）

`ci` 是截止索引，**1/48 八度一档**，`fc(ci) = 40 Hz · 2^(ci/48)`（一极点的设计频率）；
`G = q/(1+q)`，`q = tan(π·fc/fs)`；`ci` 夹到 `[0, 423]`（fc ≤ 18 kHz）。

| ci | fc（一极点） | G | 4 极点 −3 dB | K=3.75 峰值 |
| --- | --- | --- | --- | --- |
| 0 | 40.0 Hz | 0.00261 | 18.0 Hz | +14.0 dB |
| 96 | 160 Hz | 0.01036 | 70 Hz | +15.0 dB |
| 144 | 320 Hz | 0.02052 | 139 Hz | +15.2 dB |
| 192 | 640 Hz | 0.04023 | 278 Hz | +15.2 dB |
| 240 | 1.28 kHz | 0.07747 | 557 Hz | +15.2 dB |
| 288 | 2.56 kHz | 0.14467 | 1.12 kHz | +15.2 dB |
| 336 | 5.12 kHz | 0.25829 | 2.29 kHz | +15.2 dB |
| 384 | 10.2 kHz | 0.44215 | 5.06 kHz | +15.2 dB |
| 423 | 18.0 kHz | 0.70649 | 12.3 kHz | +15.2 dB |

一张 **1024×18 的 BSRAM** 装两张表：`G[0..511]`（ci > 423 的项填 fc=18 kHz 的值）与
`R[512..895]` = `1/(1+x)`，`x = K·G⁴ ∈ [0, 3.5]`，384 项覆盖 x∈[0,3.6]（分辨率 0.94%，
ZDF 修正项的误差 <0.5 dB，tb 按此设容差）。G⁴ 用两次乘法现算（G²=G·G，G⁴=G²·G²），
省掉第二张表。

### 5.4 截止上限的诚实说法（r2 修正）

一极点的设计频率可以到 18 kHz（G=0.706），但**4 极点级联的 −3 dB 只有它的一极点 fc 的约
0.43 倍**（越靠近 Nyquist 这个比例越大：5 kHz 时 0.45、15 kHz 时 0.59）。所以：

- 规格写成 **"一极点 fc 40 Hz…18 kHz；4 极点 −3 dB 18 Hz…12.3 kHz"**，两个数都给出；
- 12.3 kHz 以上没有"更开"可言——再往上就是**旁路**，不是靠推截止；
- 路线图里的"20 Hz…18 kHz"是愿望值，本设计把上面两行写进 GUI 文档，避免以后拿它去对表。

### 5.5 LFO（已定）

- 32 位相位累加：`inc = (rate_mHz · 45813) >> 9`（Q9 的 2³²/48000/1000 = 89.478，误差 <0.1%）；
- 三角：`tri = phase[31] ? ~phase[30:0] : phase[30:0]`，双极 `b = tri − 2³⁰`（±2³⁰）；
- 调制加在**对数域**：`off = (b · depth) >> 30`（depth 0..255 → ±depth 个 ci 单位；
  1/48 八度 → 最大 ±5.3 八度）；`ci_total = clamp(ci + off, 0, 423)`；
- depth=0 时截止完全不动；LFO 不改变共振与输出电平；旁路时相位**继续推进**。

### 5.6 时基与旁路（r2 新增，评审 Q2 的答复）

- 滤波器用 **`sample_ce`** 使能，而不是 mux 后的 `i2s_sample_valid`。理由：`i2s_sample_valid`
  在 LIVE 里是 `(mode_live && live_gate) && sample_ce`——手势门关掉时**一个脉冲都没有**，
  滤波器状态与 LFO 相位都会被冻住（LFO 速率就不再是 48 kHz 恒定）；而源端其实每个
  `sample_ce` 都在产生样本。
- 输出寄存器在下一个 `sample_ce` 之前就已稳定，所以**不需要**给 I2S 的 valid 加延迟，
  代价是 **1 个采样（20.8 µs）的延迟**。总延迟预算（事件→DAC ≤5 ms）里可以忽略。
- 旁路 = **输出二选一**，滤波器照常运行（状态跟着信号），因此开关瞬间没有阶跃；
  旁路时 I2S 拿到的是未滤波的 `i2s_sample`，与今天逐位相同。

## 6. 验收判据（r2 重写）

**单元（先红后绿，红证留在日志里）**

1. `tb_filter_ladder`（用 `host/filter_reference.py` 的浮点模型做黄金参考）：
   - 旁路 = 比特级直通；
   - **延迟 1 个采样**：同一个冲激，输出比输入晚一拍（不是两拍、不是零拍）；
   - K=0 时 4 极点级联的 −3 dB 与 §5.3 表对比：ci = 96 / 192 / 288 三点，容差 ±15%；
   - **共振单调**：ci=192，res = 0 / 85 / 170 / 255 的峰值单调上升，res=255 时 +15 dB ±2 dB；
   - **共振均匀性（评审要求的断言）**：res=255 在 ci = 48 / 192 / 336 三处的峰值差 ≤ 3 dB；
   - **不发散**：全量程扫描（ci 0..423 × res {0,128,255} × LFO 深度 {0,255}）每点 2000 采样，
     输出恒在 int16 内，且任何一点的最大值不得超过 32767（这是"不发散"的唯一判据）；
   - 饱和不回绕：给一个 4 倍满幅的正弦，输出是平顶而在 0 附近不出现反相尖峰。
2. `tb_lfo_triangle`：速率字 → 周期（±2%）；depth=0 时 ci 恒定；depth=255 时偏移峰峰 =
   2×255 ci 单位；ci 夹在 [0,423]；旁路时相位继续推进。

**回归**：`gate.py --compile` 0/0、`sim.py` 13 pass / 4 基线失败、`test_potts_plane` PASS。

**构建（是门，不是记录——评审 Q3 的答复）**：
`SYNTH: PASS` **且** CLS ≤ 11000 **且** worst slack ≥ −3.5 ns（不得比基线 −3.214 再差 0.3 ns）
**且**新增逻辑所在的锥里不出现新的违约端点。任一条不满足 → 先加流水/改结构再构建，
不允许带着更差的时序进入板级。

**板上**（要手）：
- 默认旁路时 `board_wt_voice_play.ps1` 通过，且听感与 P1 结束时一致；
- 写 `0x40 = 0x0100_00C0`（使能 + ci=192 ≈ 640 Hz 一极点）听"变暗"；
- 写 `0x44 = 0x0180_0500`（使能 + 速率 1280 mHz + **深度 128**，评审 Q4 修正）听"扫动"；
- 旁路/开启 A/B 各听一次；**没有量到频谱就不写"通过"**，只写"听到了什么"。

## 7. 风险与对策

| 风险 | 对策 |
| --- | --- |
| 高 K 固定点发散 | ZDF 保证 Kcrit=4 与截止无关，K 上限 3.75；再加输出饱和作为兜底；§6 全量程扫描 |
| ZDF 解算的倒数表误差 | 384 项（0.94%），修正项误差 <0.5 dB，tb 容差按此设 |
| 旁路↔开启切换爆音 | 滤波器在旁路时照常运行，只切输出（§5.6） |
| 共振让整体电平变高、削顶 | 输出饱和；若实测整体过响，加一个常数衰减（不引入 CSR） |
| CLS 上涨 | 预算 ≤450 LUT；超 11000 CLS 先回收 patch bank（763 LUT） |
| 时序 | 1667 时钟/采样；worst slack 是**门**（§6），不合格先加流水 |
| 契约改动 | `0x40/0x44` 从未实现，只有契约包与两份文档提到（评审已核实），无历史依赖 |

## 8. 我替你定的（可推翻）

1. **默认旁路**，只写在 `0x40[24]` / `0x44[24]`；
2. 共振曲线 `K = res·3.75/256`，**均匀**（+14~+15 dB），**不做自激**；
3. 用 `sample_ce` 做时基，接受 1 个采样延迟（§5.6）；
4. LFO 双极、加在对数域；
5. 采样率固定 48 kHz；
6. 并行乘法器，不时分复用；
7. 时序是门（§6），不是"记录下来就行"。

连续原型求。
