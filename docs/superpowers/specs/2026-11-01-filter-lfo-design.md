# 整机低通滤波器 + LFO 扫截止：设计（2026-11-01）

> 目标版本：`mgc3130_clean` HEAD 之后（P1 已完成）。本文件是 P2 的设计，批准后才写任务级计划。

## 1. 意图与为什么

现在的音色薄，根因不是振荡器不够，而是**没有任何频谱塑形**：32 个声部把满幅波表直接送进 I2S，
高次谐波全在，听感"亮而空"。标准合成器的听感一半来自滤波器——尤其是**带共振的低通**与
**缓慢扫动的截止频率**（LFO → cutoff）。赛题的"表情"项也希望整机有可听、可演示的连续变化。

所以 P2 做两件事，且只做两件：一个**整机共用的 4 极点低通**（24 dB/oct，带共振，可自激），
一个**三角 LFO**把截止频率在对数域上缓慢扫动。上电默认**旁路**，行为与今天完全一致；
主机显式打开后才改变音色，因此既往验收过的电平/频谱证据不会失效。

## 2. 目标

1. 三条音频出口（`PLAY` 的 32 声部、`LIVE` 单声部、`WT_PLAY` 台架）都经过同一个滤波器；
2. 截止频率、共振、LFO 速率/深度可经 CSR 控制，且**可读回**；
3. 旁路时**比特级透明**（输入直通，不引入一步延迟的差分）；
4. 任何 (截止 × 共振 × LFO) 组合都不发散：输出恒在 int16 内，最坏是自激限幅；
5. 面积 ≤ 400 LUT、≤ 7 DSP、0 BSRAM（预算：CLS 剩 1010、DSP 剩 20、BSRAM 剩 19）。

## 3. 非目标 / 反目标

- 不做滤波包络（ADSR→截止）、不做键盘跟踪（keytrack）、不做高通/带通/陷波；
- 不做每声部独立滤波（整机一个，这是用户已定的）；
- 不做 LFO 波形选择（只有三角）、不做 LFO 同步到 BPM；
- 不重做效果器（`v2_fx_lite` 保持原样）；
- **反目标**：为了"更 hifi"把截止上限吹到 18 kHz——见 §5.4，24 dB/oct 在 48 kHz 下做不到，
  写进文档而不是假装做到。

## 4. 约束（来自现有代码，不是猜的）

| 约束 | 值 | 出处 |
| --- | --- | --- |
| 采样率 / 时钟 | 48 kHz / 80 MHz → **每个采样 1667 个时钟** | `i2s_pcm5102a_tx` `CLK_HZ(80e6) SAMPLE_HZ(48e3)` |
| 插入点 | `i2s_sample` 的 4 路 mux 之后（三条出口都经过） | `mgc3130_v2_top.sv:658` |
| 一个采样的使能 | `i2s_sample_valid`（每采样一个脉冲） | 同上 606 |
| 面积余量 | CLS 10510/11520、DSP 8/28、BSRAM 37/56 | `impl/v2_board_top_vca_detune_mbox` |
| 时序余量 | worst −3.214 ns（在 UART，不在音频路径） | 同上 `.tr` |

**关键推论**：1667 个时钟/采样意味着滤波器可以做成多周期串行，但 **DSP 富余、LUT 紧张**，
所以实现用**并行的 5~7 个乘法器**（每级一个），不做时分复用——用充裕的资源换简单和可读。

## 5. 方案

### 5.1 三个候选与取舍（用户选了 B）

| | 结构 | 音色 | 代价 |
| --- | --- | --- | --- |
| A | 状态变量 12 dB/oct，`g=tan(πfc/fs)` | 干净、Q 可到 8、扫频平滑 | tan 要靠查表+插值（1 BSRAM + ~150 LUT） |
| **B ✅** | **梯形 4 极点 24 dB/oct，系数 `g=(32+f)>>(k+5)` 的 32 项小表** | **最像合成器：厚、有共振峰、高 K 自激** | 无 BSRAM；4 级乘法 + 反馈乘法；反馈路要限幅 |
| C | 两级一极点级联 12 dB/oct，无共振 | 只压高频，仍单薄 | 最便宜（~80 LUT），放弃共振 |

选 B 的理由：用户诉求是"音色单薄"，24 dB + 共振最能改观；系数在对数域（每 1/32 八度一档），
LFO 直接加在对数域上就是音乐化扫频；不动 BSRAM，92% 占用下更安全。

### 5.2 结构（已定）

```
x ──►(+)──► [g/(1-(1-g)z⁻¹)]⁴ ──► y4 ──► 饱和 ──► out
      ▲-                        │
      └────── K ◄──── 限幅 ◄────┘        (反馈取上一采样，含饱和)
```
- 每级一极点用 RC 形式：`y_i += g * (u_i - y_i)`，`u_1 = x - K*y4_prev`，`u_i = y_{i-1}`；
- 反馈路径先做 **int16 硬限幅**（成本≈0），高 K 时的自激被限成有界极限环而不是发散；
- 输出再做一次 int16 饱和（共振峰值可超过输入满幅）；
- **K 上限 3.9**（K=4 是振荡阈值）：`K = min(res * 4 / 256, 3.9)`，`res` 为 0..255。

### 5.3 系数与截止映射（已定）

`ci`（截止索引，12 位）= 32·k + f，`g = LUT32[f] >> k`，`LUT32[f] = round(32768·2^(-f/32))`
（32 项 × Q15，实测表值 f=0/8/16/24/31 → 32768/27554/23170/19484/16743）。

| ci | g | 一极点 fc | 4 极点 −3 dB |
| --- | --- | --- | --- |
| 0 | 1.0 | 全开 | 全开 |
| 8 | 0.8409 | 14.0 kHz | 7.3 kHz |
| 16 | 0.7071 | 9.4 kHz | 4.4 kHz |
| 32 | 0.5000 | 5.3 kHz | 2.4 kHz |
| 64 | 0.2500 | 2.2 kHz | 959 Hz |
| 96 | 0.1250 | 1.02 kHz | 444 Hz |
| 128 | 0.0625 | 493 Hz | 215 Hz |
| 192 | 0.0156 | 120 Hz | 53 Hz |
| 256 | 0.0039 | 29.9 Hz | 13 Hz |
| 272 | 0.0027 | 21.0 Hz | 10 Hz |

- 数字一极点的 `f = -ln(1-g)·fs/2π`；4 极点级联的 −3 dB 在**一极点 fc 的约 0.43 倍**处
  （多一个极点就多一段滚降）。表内的数是算出来的，tb 用来做 ±15% 的核对；
- ci 超过 480 时 g=0（全关）；实现里把 ci 夹到 `[0, 480]`。

### 5.4 截止上限的诚实说法

24 dB/oct 在 48 kHz 下**不可能**有 18 kHz 的 −3 dB 点：级联 4 个一极点的 −3 dB 只有一极点 fc 的
0.43 倍，而一极点 fc 最多到 fs/2=24 kHz。可达的 −3 dB 上限约 **12 kHz（ci≈4）**，再往上等于"全开"。
路线图里写的"20 Hz…18 kHz"是愿望值，本设计把规格改成 **−3 dB 范围 10 Hz…约 12 kHz，
12 kHz 以上视为全开**，并写进 GUI 文档，避免以后拿 18 kHz 去对表。

### 5.5 LFO（已定）

- 32 位相位累加：`inc = (rate_mHz * 45813) >> 9`（Q9 的 2³²/48000/1000 = 89.478，误差 <0.1%）；
- 三角：`tri = phase[31] ? ~phase[30:0] : phase[30:0]`，双极 `b = tri - 2^30`（±2^30）；
- 调制量加在**对数域**：`off = (b * depth) >>> 30`（depth 0..255 → ±depth 个 ci 单位 = ±depth/32 八度，
  即最大 ±8 八度）；`ci_total = clamp(ci + off, 0, 480)`；
- depth=0 时截止完全不动；LFO 不改变共振与输出电平。

## 6. 验收判据

**单元（先红后绿，红证留在日志里）**

1. `tb_filter_ladder`：
   - 旁路 = 比特级直通（同一组输入，旁路输出 == 输入）；
   - 正弦扫频测 4 极点 −3 dB 点：ci = 32 / 96 / 192 三档，与 §5.3 表对比，容差 ±15%；
   - res=0 时与理想 4 极点级联的幅度误差 < 2 dB（1 kHz 处）；
   - res 升高时 ci=96 的峰值单调上升；res=255 时不自激发散（|out| ≤ 32767 且无 NaN 式跑飞）；
   - 全量程扫描（ci 0..480 × res 0,128,255，每点 2000 采样）不出现发散。
2. `tb_lfo_triangle`：速率字 → 周期（±2%）；depth=0 时 ci 恒定；depth=255 时偏移峰峰 =
   2×255 ci 单位；ci 夹在 [0,480]。

**回归**：`gate.py --compile` 0/0、`sim.py` 13 pass / 4 基线失败、`test_potts_plane` PASS。

**构建**：`SYNTH: PASS`，记录 LUT/Reg/CLS/DSP/BSRAM + 时序四个数；CLS 不得超 11000（留 500）。

**板上**（要手）：
- 默认旁路时，`board_wt_voice_play.ps1` 通过且听感与 P1 结束时一致；
- 写 `0x40 = 0x0100_00C0`（使能 + ci=192）听"变暗"，再写 `0x44 = 0x0100_0500`（使能 + 速率 1280 mHz、
  深度 128）听"扫动"；旁路/开启 A/B 各听一次；
- 没有量到频谱就不写"通过"，只写"听到了什么"。

## 7. 风险与对策

| 风险 | 对策 |
| --- | --- |
| 高 K 固定点发散 | 反馈硬限幅 + K 上限 3.9 + §6 的全量程扫描用例 |
| 旁路↔开启切换爆音 | 旁路时状态保持不清零；打开时从当前状态继续（渐变由 LFO/截止决定，不做淡入） |
| 共振让整体电平变高、削顶 | 输出饱和；若实测整体过响，加一个常数衰减（不引入 CSR） |
| CLS 上涨 | 预算 ≤400 LUT；超 11000 CLS 先回收 patch bank（763 LUT） |
| 时序 | 滤波器在 48 kHz 侧，每采样 1667 时钟；即便落进关键路径，也能两级流水 |
| 契约改动 | `0x40/0x44` 从未实现，只有契约包与两份文档提到，无历史依赖（已核对） |

## 8. 我替你定的（可推翻）

1. **默认旁路**，且只写在 `0x40[24]` / `0x44[24]`——不靠"截止全开"假装透明；
2. 共振曲线 **K = res·4/256，夹到 3.9**。注意 K 到 3.9 时峰值只有 +1 dB，K=4 才自激，
   所以共振旋钮的"有效区间"集中在 res 220..255；这是梯形滤波器的固有特性（真 Moog 也这样），
   不额外做曲线整形，GUI 文档里注明；
3. LFO 用**双极**三角（扫动的中心 = 设定的截止），不做单极；
4. LFO 的调制在**对数域**（ci 加法），因此同一深度在低音区和高音区的听感一致；
5. 采样率固定 48 kHz，不跟随 I2S 参数变化（现在也只有 48 kHz）；
6. 实现用并行乘法器而不是时分复用（DSP 富余、LUT 紧张）。
