# 谱（score）：给盲录用的指引

LOOP 页顶部选一张谱，画布就把**正在录的那一轨**每个 tick 的目标档填亮；录完 32 点轮廓一比，
状态栏右边给出命中率。这是绕开"录音时听不到别的轨"的办法：不需要听，只需要知道手什么时候到哪一档。

## 文件格式

```json
{ "schema": 1, "name": "c-am-vamp-4s", "bpm": 120, "ticks": 32,
  "tracks": [
    { "track": 0, "role": "bass", "notes": [[0, 55], [8, 55], [16, 57], [24, 57]] }
  ] }
```

- `notes` 是 `[起始 tick, MIDI 音号]`，长度由下一个起点或 32 决定；连续同音会并成一个 hold。
- `ticks` 只能是 32（4 s @ 120 BPM，`rtl/v2_loop_scheduler #(.LOOP_TICKS(32))`）。
- `bpm` 只能是 120：`record_flow.arm` 强写 `0x08=120` 并读回校验，别的速度会和画出来的小节错位。
- `track` 0..5（`record_track_count[0:5]`），同一张谱里不重复。

## 能用的音只有八个

| 音 | G3 | A3 | C4 | D4 | E4 | G4 | A4 | C5 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| MIDI | 55 | 57 | 60 | 62 | 64 | 67 | 69 | 72 |
| 轮廓 y（0..1023） | 0–59 | 60–210 | 211–360 | 361–481 | 482–631 | 632–782 | 783–933 | 934–1023 |
| 中点（DP 拟合） | 30 | 135 | 286 | 421 | 557 | 707 | 858 | 978 |
| 原始 y（×64） | 1920 | 8640 | 18304 | 26944 | 35648 | 45248 | 54912 | 62592 |

来源：`rtl/v2_note_increment_rom.sv`（只有这 8 个相位增量）、`rtl/v2_live_rule_engine.sv:96-103`
（y 阈值 3855/13493/23130/30840/40478/50115/59753，除以 64 即上表）、
`v2_loop_contour_capture.sv:57`（轮廓存的是 `y[15:6]`）。

**档位不是八等分**：G3 只有 60 宽，A3 有 151 宽。画布按真实区间画，所以图上那条带子有多高，
手上就有多大空间。

## 写一张新谱

1. 先决定和声与每小节换几次（一个 tick = 一个 16 分音符 = 125 ms）；
2. 每段至少 4 tick（`host/v2_potts_reference.py` 的 `MIN_RUN = 4`），8 tick 更稳；
3. 不要留休止：轮廓非零要 ≥30/32（`record_flow.py` 的 `MIN_COVERAGE = 30`），所以每条轨都是 legato 线；
4. 把 JSON 放进本目录，重启控制台或重新选一次谱即可（下拉列表在启动时扫目录）。

校验在 `host/v2_console/score.py`：音不在 8 个里、tick 越界或倒序、速度不是 120、同一轨出现两次，
都会在载入时报出是哪一行。

## 命中率怎么算

`score.judge(contour, targets)`：对每个 tick 取轮廓值 → 用上面同一套阈值换回音号 → 和目标比。
**没手（轮廓 0）算错**，因为提交后那里是休止；所以 30/32 的覆盖率门禁和命中率说的是同一件事。

界面显示 `命中 n/32`，后面列出错的 tick 号（最多 10 个）。
